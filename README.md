# Golden Agro Foodz website

Single-page site (index.html + images/) for Golden Agro Foodz, Baba Bakala Sahib, Amritsar.
Honey, mustard oil, turmeric powder and eggs, with a cart that sends the order on WhatsApp.

Prices in the `PRODUCTS` object near the bottom of `index.html` are placeholders. Edit them there.

Deploy: import the repo in Vercel (no build step, output is the repo root).
